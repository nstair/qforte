Informal test how-to and TODOs
==============================

Important environment rule
--------------------------
Use qf-cusv1 for these informal tests unless the user explicitly asks for a
different conda environment.

Maintenance rule
----------------
Whenever a new informal test is added, update this file in the same change so a
future Codex run can read only this file and correctly rerun the informal test
suite for output validation.


General notes
-------------
Run commands from the repository root.

These tests are intentionally informal scripts, not pytest tests.  Most scripts
write detailed logs under ignored log directories and print compact PASS/SKIP
tables to the terminal.

Default command form:

    conda run -n qf-cusv1 python path/to/script.py

If the user explicitly requests another environment, substitute it in the
commands below.

Do not refresh expected/reference outputs unless the user explicitly asks for
that.  Normal validation runs should not overwrite saved references.


SRQK informal tests
-------------------
Directory:

    informal_tests/srqk_fci_comp

Current molecule/reference system:

    linear H4 at z = 1, 2, 3, 4 angstrom, STO-3G, symmetries c1 and d2h

Reference/validation run:

    conda run -n qf-cusv1 python informal_tests/srqk_fci_comp/run_srqk_fci_comp.py

Backend parity run:

    conda run -n qf-cusv1 python informal_tests/srqk_fci_comp/run_srqk_backend_parity.py

Low-memory backend parity run:

    conda run -n qf-cusv1 python informal_tests/srqk_fci_comp/run_srqk_low_memory_backend_parity.py

Current status note:

    In qf-cusv1, SRQK backend parity now passes for fock, fqe, fci_gpu, and
    cusv, including the Python-side final-state <S^2> and NOON diagnostics.

Important regression clue:

    If SRQK energies/matrices still agree but reconstructed-state diagnostics
    drift, first inspect src/qforte/maths/eigsolve.py.  A prior bug reordered
    X_prime along with the sorted generalized eigenpairs, which left the
    eigenvalues correct but corrupted the returned eigenvectors used for final
    state reconstruction.

Only refresh the saved SRQK expected JSON after reviewing intentional numerical
changes:

    conda run -n qf-cusv1 python informal_tests/srqk_fci_comp/run_srqk_fci_comp.py --write-expected

Optional helpers:

    conda run -n qf-cusv1 python informal_tests/srqk_fci_comp/run_srqk_fci_comp.py --list-cases
    conda run -n qf-cusv1 python informal_tests/srqk_fci_comp/run_srqk_backend_parity.py --list-backends

PySCF dump API informal tests
-----------------------------
Directory:

    informal_tests/pyscf_fci_dump_api

The PySCF dump API tests use small saved dumps in:

    informal_tests/pyscf_fci_dump_api/dumps

The dump files should be committed because they are the stable input data for
these informal checks.  Generated logs and __pycache__ directories should not be
committed.

Generate missing dumps or confirm existing dumps are present:

    conda run -n qf-cusv1 python informal_tests/pyscf_fci_dump_api/run_generate_pyscf_dumps.py

Only overwrite dumps after reviewing intentional changes to the dump data:

    conda run -n qf-cusv1 python informal_tests/pyscf_fci_dump_api/run_generate_pyscf_dumps.py --overwrite

BeH2 molecule-build parity:

    conda run -n qf-cusv1 python informal_tests/pyscf_fci_dump_api/run_beh2_dump_molecule_parity.py

Benzene AVAS molecule-build parity:

    conda run -n qf-cusv1 python informal_tests/pyscf_fci_dump_api/run_benzene_avas_dump_molecule_parity.py

VQE/SRQK algorithm parity across available molecule builds:

    conda run -n qf-cusv1 python informal_tests/pyscf_fci_dump_api/run_dump_algorithm_parity.py

Environment expectations:

    - A qforte-enabled environment without PySCF can still run dump-side checks
      and Psi4-vs-dump BeH2 algorithm parity if Psi4 is available.
    - Direct PySCF molecule-build checks require PySCF in the selected
      environment.
    - If a script prints SKIP, read the printed reason and associated log path.


Hamiltonian application informal tests
--------------------------------------
Directory:

    informal_tests/ham_application

These checks build the BeH2 and benzene AVAS molecules from the committed
PySCF dump files, then compare Hamiltonian-application outputs from several
computer backends against saved FCI tensor sigma vectors.

Validation run:

    conda run -n qf-cusv1 python informal_tests/ham_application/run_ham_application.py

Only refresh the saved FCI tensor reference sigma vectors after reviewing the
current FCI tensor outputs:

    conda run -n qf-cusv1 python informal_tests/ham_application/run_ham_application.py --write-reference

Optional helpers:

    conda run -n qf-cusv1 python informal_tests/ham_application/run_ham_application.py --list-systems
    conda run -n qf-cusv1 python informal_tests/ham_application/run_ham_application.py --list-backends
    conda run -n qf-cusv1 python informal_tests/ham_application/run_ham_application.py --list-cases
    conda run -n qf-cusv1 python informal_tests/ham_application/run_ham_application.py --system beh2
    conda run -n qf-cusv1 python informal_tests/ham_application/run_ham_application.py --system benzene --backend fock

Reference files that should be committed:

    informal_tests/ham_application/reference_states/beh2_fci_tensor_sigma_reference.npz
    informal_tests/ham_application/reference_states/benzene_fci_tensor_sigma_reference.npz

Generated logs and __pycache__ directories should not be committed.


Pre-commit cleanup reminders
----------------------------
Before committing, check that generated files are not accidentally staged:

    git status --short --ignored informal_tests sandbox src

Expected generated files/directories to leave untracked or ignored:

    __pycache__/
    logs/
    backend_logs/
    low_memory_logs/
    informal_tests/ham_application/logs/
    output.out
    timer.dat
    dmrg.out
    src/qforte.egg-info/
    compiled qforte .so/.dylib artifacts

Expected PySCF dump API files to keep:

    informal_tests/pyscf_fci_dump_api/dumps/*.npz
    informal_tests/pyscf_fci_dump_api/dumps/*.FCIDUMP

Expected Hamiltonian application reference files to keep:

    informal_tests/ham_application/reference_states/*.npz
